# Poly Haven Texture Assets

These Demo V1 texture maps were downloaded from Poly Haven's public API for the AeroStrike warehouse scene.

License: CC0 / public domain. Source: https://polyhaven.com/license

API documentation: https://api.polyhaven.com and https://github.com/Poly-Haven/Public-API

Downloaded resolution: 1k JPG maps to keep the repo small and Isaac startup practical.

## Assets

| Local folder | Poly Haven asset | Source page | Maps |
|---|---|---|---|
| `concrete_floor_worn_001` | Concrete Floor Worn 001 | https://polyhaven.com/a/concrete_floor_worn_001 | diffuse, roughness, normal |
